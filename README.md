# Qalam

Simple book review project for learning microservices architecture with user, book and review services


## Features

**User**
- View detailed book information
- Add reviews to books
- Add rating to books
- Like other user's reviews
- Add reports to reviews

**Admin**
- Manage book, author and genre data
- View user reports
- View and delete reviews


## Tech stack

- Go
- Postgres
- RabbitMQ
- Docker
- Golang-migrate
- JWT
